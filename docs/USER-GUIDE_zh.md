# muse-thinktank 用户使用说明

> 给普通 Muse 用户：不用写代码，跟着做就行。

[English](USER-GUIDE.md)

---

## 这是什么？

你在 Muse 里问一个问题，Muse 把它同时发给好几个 AI，让它们各自回答，再由裁判挑出最好的、整合成一份结论给你。比只问一个 AI 更靠谱。

**举例**：你问"特斯拉股票未来怎么样？"——3 个 AI 各自分析，裁判选出最靠谱的，Muse 整合成报告。

## 三步用起来

### 第一步：准备 API Key（2 分钟）

智囊团要调用多个 AI 模型，需要一把"钥匙"（API Key）。

1. 打开 https://openrouter.ai/keys
2. 注册/登录（可以用 Google 一键登录）
3. 点 **Create Key**，复制那串 `sk-or-v1-...` 开头的字符
4. **免费模型不花钱**——日常用完全够

> 目前只支持 OpenRouter，未来会支持更多渠道。

### 第二步：告诉 Muse 连接

在 Muse 里说一句话：

> **"Connect to OpenRouter"**

Muse 会给你一个安全链接，点开、粘贴刚才复制的 Key，确认。Key 存在安全的地方，Muse 看不到明文，你放心。

### 第三步：复制这句话给你的 Muse

复制下面这段，粘贴到 Muse（或其他 AI，如 Grok）的聊天框里发送：

```
请帮我安装这个开源项目：https://github.com/stoneskin/muse-thinktank

按它仓库里 AI_SETUP.md 的步骤操作。
需要 API key 的地方停下来，先告诉我去 https://openrouter.ai/keys 免费申请一个。
```

AI 会自动：下载 → 检查环境 → 跑测试 → 告诉你"装好了"。

> 不用你碰终端，不用懂编程。

## 开始用

装好后，直接在 Muse 里说：

- **"上智囊团，分析下特斯拉股票"**
- **"议一议，PostgreSQL 和 MongoDB 选哪个？"**
- **"让几个模型讨论一下，这个方案有什么风险？"**

Muse 会先告诉你大概要花多少钱、多久（免费模型是 $0），你说"去"就开始。

## 常见问题

**Q：要花钱吗？**
A：用免费模型一分钱不花。Muse 每次跑之前会先告诉你费用，你确认后才跑。

**Q：要懂编程吗？**
A：不用。你只管在 Muse 里说话，安装、运行都是 Muse 替你做。

**Q：问股票靠谱吗？**
A：靠谱，但有个前提——AI 的训练数据是旧的。Muse 会先去搜最新股价、财报数据，再让智囊团分析，保证用的是真数字。

**Q：等很久没反应？**
A：免费模型偶尔排队。Muse 会实时告诉你进度，哪个模型在跑、还要多久。

**Q：换手机了怎么办？**
A：Key 存在你的 Muse 账号里，换设备不用重新设。重说"安装 muse-thinktank"就行。
