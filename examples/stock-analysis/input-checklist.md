# 股票分析输入数据检查表 v1

跑智囊团之前，Muse 按此清单准备实时数据，注入 `--context-data`。
搜不到的明确标 `[数据缺失]`，不让模型猜。

## 基本面（5 大类）

### 1. 利润表拆解
- 最新季度营收、EPS（实际 vs 共识）
- 毛利率分项（剔除一次性/监管积分后）
- 高毛利业务收入占比（如 FSD、云、订阅）
- OpEx 细目（研发 vs 销售管理）

### 2. 现金流
- 自由现金流（FCF）
- 资本开支（CapEx）及下季度指引
- 现金储备变化

### 3. 核心 KPI
- 库存天数 / 渠道库存
- 订单净增长率
- 关键业务渗透率（如 FSD 付费率、云增速）
- 主要产品均价 / 毛利趋势

### 4. 催化剂时间表
- 下次财报日期
- 新品 SOP / 发布节点
- 监管 / 政策节点
- 管理层指引（交付、营收、利润）

### 5. 资金面（基本面侧）
- 机构持仓变化（13F 季度对比）
- 内部人买卖
- 分析师评级修订及目标价分布

## 技术面（5 大类）

### 1. 价格历史
- **250 天日 K 线**（覆盖完整财报周期 + 200 日线）
- 104 周周 K 线（大方向过滤噪音）

### 2. 必备指标（Top 8）
| 指标 | 回答的问题 |
|---|---|
| SMA 50 / 200 | 长/中趋势方向、生死叉 |
| VWAP | 机构成交中枢、公平价 |
| RSI(14) | 超买超卖、背离 |
| MACD(12,26,9) | 趋势动能转折 |
| ATR(14) | 波动率、止损距离 |
| 布林带(20,2) | 波动收缩/扩张、突破真假 |
| OBV | 量价背离、主力进出 |
| 周线 MACD/均线 | 大方向定调 |

### 3. 大盘关联
- SPY/QQQ 同周期走势
- 板块 ETF 相对强弱
- 60 日滚动相关系数
- Beta（含下行 Beta）

### 4. 资金面（技术面侧）
- 成交量（趋势确认）
- 期权 PCR（情绪极值）
- 做空比例 / 融券余额
- Max Pain（期权到期磁吸）
- Dark Pool 大单流向（如有）

### 5. 关键位
- 支撑位（具体价格，至少 2 个）
- 阻力位（具体价格，至少 2 个）
- 当前价格在 52 周区间分位
